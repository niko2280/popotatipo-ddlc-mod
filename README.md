# ПОПОТАТИПО: ПОБЕГ ИЗ ПОДЪЕЗДА (DDLC Mod)

Хоррор-мод для **ванильной Doki Doki Literature Club**.

Моника, Юри, Нацуки и Сайори застряли в 10-этажном российском подъезде. Вход заварен. По подъезду гоняет **ПОПОТАТИПО** — без майки, в трусах, в сварочной маске. Он говорит только «ПОПОТАТИПО» и «ДАВАЙ». Иногда несёт бред. Ваша задача — сбежать, пока он не догнал вас с аппаратом.

**6 концовок.** Включая плохую, очень плохую и одну странно трогательную.

## Установка

1. Нужна ванильная DDLC (Steam или itch.io версия).
2. **Скопируй** всю папку с игрой в отдельное место. Оригинал не трогаем.
3. Скачай этот репозиторий: зелёная кнопка **Code -> Download ZIP**.
4. Из архива возьми папку `game` и скопируй её **содержимое** (`script.rpy`, `popotatipo.rpy`) в папку `game` твоей копии DDLC.
5. Удали папку `saves` внутри копии игры (если есть).
6. Запусти игру как обычно (`DDLC.exe` / Steam). Мод стартует сразу.

## Фото Попотатипо (опционально, но круто)

Мод умеет показывать твои фотографии Попотатипо:

- `popo1.png` — обычный Попотатипо
- `popo2.png` — Попотатипо со сваркой
- `popo3.png` — Попотатипо крупным планом

Положи их прямо в папку `game` твоей копии DDLC — мод подхватит их автоматически. Если фото нет, будут тёмные экраны-заглушки (атмосферно, но так лучше).

## Концовки

Всего 6: **СВАРКА**, **ДАВАЙ**, **СВОБОДА**, **МЧС**, **ПОДЪЕЗД НАВСЕГДА**, **ИСТИНА**.

Сюжет длинный, с большими развилками: лифт, лестница, подвал, шахта лифта, крыша. Твои решения копят уровень опасности — если нахамировать, Попотатипо вас достанет.
